## 1. 设计目标与关键词

**一句话**：一款极简的本地日记 App —— 打字、说话、拍照，想怎么记就想怎么记。

**设计关键词**：克制、留白、温暖、无压力。
**用户感受目标**：打开它像翻开一本干净的本子，而不是进入一个"产品"。

**核心气质参照**：Apple 手记（Journal）的系统级克制 + Day One 的卡片时间轴。取二者的"安静"，不取任何花哨。

## 3. 硬性规范（不可更改）

### 3.1 平台与组件

- iOS 26 · iPhone · 竖屏 · 遵循 Apple HIG（Human Interface Guidelines）。
- **不用 TabBar**。导航结构：首页 →（sheet 弹出）写日记页；首页 →（push）详情页；首页 → 设置页。
- 图标一律使用 **SF Symbols**，不自绘图标（开发时一行代码调用）。

### 3.2 字体（系统字体，不引入任何第三方字体）

| 角色 | 字体 / 字号 | 用途 |
|---|---|---|
| 大标题 | SF Pro / 苹方 · 34pt Bold | 首页 "随心记"（Large Title） |
| 卡片日期数字 | 22pt Semibold | 卡片左侧的"4日"，视觉锚点 |
| 正文 | 17pt Regular · 行高约 1.5 | 日记正文、输入区 |
| 摘要 | 15pt Regular · secondaryLabel 色 | 卡片里的正文前两行 |
| 辅助 | 13pt / 11pt | 月份分组标题、工具栏文字标签、时长 |

### 3.3 颜色（语义色优先，主题色只做点缀）

| 名称 | 值 | 用途 |
|---|---|---|
| 主题色 Accent | `#FF8A5C` 暖橙 | 悬浮 ➕、保存按钮、录音波形、选中态 —— **仅点缀，不做大面积铺色** |
| 页面背景 | iOS `systemBackground` | 浅色纯白 / 深色纯黑，跟随系统 |
| 卡片背景 | iOS `secondarySystemBackground` | 时间轴卡片、录音条 |
| 主文字 / 次文字 | `label` / `secondaryLabel` | 正文 / 摘要与辅助信息 |
| 录音进行中 | iOS `systemRed` | 录音红点与计时 |

### 3.4 尺寸

卡片圆角 **16pt** · 页面左右边距 **16pt** · 卡片间距 **12pt** · 悬浮 ➕ 直径 **56pt**（距右下角 16/24pt）· 图片缩略 60pt 圆角 8pt · 九宫格图 80pt。

## 4. 逐页设计要求

### ① 首页 · 时间轴

- 顶部：Large Title「随心记」，下方 secondaryLabel 显示今天日期"7月4日 星期六"；右上角 ⚙️（`gearshape`）。
- 列表按"年-月"分组，分组标题 13pt secondaryLabel（如"2026年7月"）。
- **卡片结构**（信息层级从强到弱）：左侧大号日期数字"4日"+ 星期小字 → 正文摘要 2 行 → 图片缩略行（最多 3 张，多余的显示"+N"）→ 右上角 🎙️ 时长角标（如"🎙️ 0:35"，仅有录音时显示）。
- 右下角悬浮 ➕：主题色圆形按钮，阴影轻（y=2 blur=8 透明度 ≤15%）。
- 本地 App，无下拉刷新、无网络态。

### ② 写日记页（sheet 弹出，新建 / 编辑共用）

- sheet 顶部带系统 grabber；导航行：左「取消」· 中间日期胶囊「7月4日 ▾」（可点击改日期）· 右「保存」（主题色，内容全空时置灰禁用）。
- 正文输入区占据主要空间，占位文案「今天想说点什么…」。
- 正文下方依次是：图片九宫格（含虚线 ➕ 追加格，每张右上角 ✕）→ 录音条。
- **录音条**：圆角胶囊，结构 = ▶ 播放键 + 波形 + 时长 00:35 + ✕ 删除。每篇最多 1 条。
- 底部工具栏 3 个入口（图标 + 11pt 文字标签）：🎤 转文字（`mic`）· 🎙️ 录音（`waveform`）· 🖼️ 图片（`photo`）。

### ③ 详情页（push 进入）

- 导航栏标题「7月4日 星期六」，右上 `ellipsis.circle` 菜单（编辑 / 删除，删除为红色 destructive）。
- 内容顺序：心情 emoji（如有）→ 录音播放条（▶/⏸ + 进度 + 时长）→ 完整正文 → 图片网格（点击进入横滑大图，系统 pager 风格）。

### ④ 设置页

- 系统 grouped list 风格，仅三组：每日提醒（开关+时间，P1 先做占位样式）· 关于（版本号）· 底部 footer 文字：**「日记仅保存在本机，删除 App 将丢失全部数据。」**（必须出现，不可省略）。

## 5. 必做的关键状态

| 状态 | 设计要求 |
|---|---|
| **首页空状态** | 一句引导「记录今天的第一条心情吧」+ 极简线条元素，视线引向 ➕；不要大幅插画 |
| **录音中** | 底部工具栏切换为录音状态条：红点呼吸 + 计时 00:00 递增 + 波形动画 + 停止按钮；用户必须一眼知道"正在录" |
| **权限引导** | 系统 alert 样式：「需要麦克风权限」+ 说明一句 + 「取消 / 去设置」 |
| **删除确认** | 系统 alert：「删除后不可恢复，确定删除这篇日记吗？」，删除按钮红色 |
| **保存禁用态** | 内容全空时「保存」灰色不可点 |
| **深色模式** | 语义色体系下自然成立，出首页+写日记页两屏验证即可 |

---

## 6. 动效说明（少而准）

1. 保存成功：sheet 收起，新卡片在首页顶部**轻微下落插入**（约 0.3s），给"记下来了"的确认感。
2. 录音中：红点缓慢呼吸 + 波形随音量律动。
3. 除以上两处外**不加任何动效**。转场全部用系统默认。

---

## 7. 风格护栏（同样重要的"不要做什么"）

- **签名元素只有一个**：与"声音"相关的波形语言（录音条、录音中动画、播放条）是全 App 唯一允许有表现力的地方，其余一律安静克制。
- 暖橙 `#FF8A5C` 只做点缀。**不要**做成"奶油底色 + 陶土橙大标题"的整页暖色调模板风——那是最常见的 AI 生成审美，与本产品的系统级克制相悖。
- 不要拟物、不要厚阴影、不要彩色渐变、不要玻璃拟态滥用。
- 不要发明 PRD 之外的任何功能入口（如分享、标签、AI 按钮）。
- 不要非系统字体、不要自绘图标。
- 文案全部使用 PRD/本 Brief 中的真实文案，不要 Lorem ipsum 或英文占位。
